# VisionForge AI

An AI-powered image generation web application built from scratch while learning modern web development and AI integration.

## 🚧 Project Status

Currently in development.

## 🎯 Goal

Build a full-stack AI image generator that allows users to:

- Enter natural-language prompts
- Select image styles
- Select aspect ratios
- Generate AI images
- Download generated images
- View generation history
- Manage favorite images

## 🛠️ Technologies

Planned technologies:

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express.js
- MongoDB
- AI Image Generation API

## 📚 Learning Goals

This project is being built to learn:

- JavaScript

- Backend development
- AI API integration
- Database management
